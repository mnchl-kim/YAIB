# Current Task

## Goal

- Write a top-tier ML/DL conference paper on clinical irregularly-sampled time-series modeling.

### Motivation

Clinical time-series are irregularly sampled because measurements are generated by clinical need and hospital workflow.

- Some variables are routinely measured for most patients.
- Other variables are measured only when clinically indicated.
- Measurement timing is not fully determined by patient state; it is also affected by hospital workflow, routines, resources, and protocols.

### Core Insight

Conventional pipelines convert irregular observations into fixed `B x T x F` tensors.

As the feature set grows, this tensorization can increase sparsity and distort the native measurement process, instead of simply adding useful information.

### Proposed Direction

Develop a representation pipeline that avoids conventional `B x T x F` tensorization and directly models observations through:

- time
- feature
- value
